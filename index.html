AutoPilot FX EA

An ATR-based breakout straddle bot for MetaTrader 5. It brackets price with a Buy Stop and a Sell Stop sized from current volatility, follows whichever way the market breaks, cancels the other side, and re-arms once the trade closes — with an adjustable daily loss limit and built-in safety warnings.

What it does

Stop-and-reverse breakout logic, driven by volatility — or by price percentage — rather than a fixed distance.

Volatility-sized straddle

Distance from price for both pending orders is ATR × multiplier by default, so the bracket widens in fast markets and tightens in quiet ones.

Breakout direction

Whichever stop order triggers first rides the breakout. Each entry carries a tight Stop Loss and Take Profit, in points or in % of price.

OCO behaviour

When one side fills, the opposite pending order is cancelled automatically. Only one straddle (two pending orders) is ever active — no grid, no martingale.

Auto re-arm & re-center

After a trade closes on SL or TP, a fresh straddle is placed around the new price. If price drifts off without triggering, the straddle re-centers.

Key features

Safety and transparency are built in, not bolted on.

Auto mode — works on anything

Default setting. SL, TP, and straddle distance are all multiples of the instrument's own live ATR, and the spread filter compares live spread to live ATR too — so nothing is a fixed number that a given instrument could outgrow. Confirm and go, on forex, crypto, metals, or an index.

Category presets, if you'd rather

Set InpPreset to Forex, Crypto, or Metals / Index for a fixed bundle tuned to that category instead of Auto's live calibration. Pick Custom to control every number by hand.

OCO straddle engine

Buy Stop above, Sell Stop below; first fill wins, the other order is pulled.

Fixed-points or %-of-price mode

Under Custom mode, calculate SL, TP, and straddle distance as raw points off an ATR reading, or as a percentage of price — useful for instruments where a fixed point count doesn't scale, like crypto pairs.

Adjustable daily loss limit

Halts trading for the rest of the day once losses hit a cap — a percentage of the day-start balance or a fixed amount. Optionally closes any open position when the limit is reached.

Spread filter

Skips placing new orders when the spread is wider than your threshold, to avoid entering during news spikes.

Optional chop/trend filter

Off by default. InpUseChopFilter pauses placing a new straddle when live ADX reads below InpMinADX — the ranging conditions this strategy tends to whipsaw in. Only delays arming a fresh straddle; never touches a trade that's already open.

Input sanity-check warnings

On load, the EA checks your settings against recommended safe ranges and raises an Alert plus a detailed log explanation for anything outside them. It still runs with your values — the warning is informational.

On-chart dashboard

Live status panel showing current state, today's P/L, and whether the daily limit has been hit.

Single self-contained file

One .mq5, no dependencies, no DLLs. Compile in MetaEditor and run.

Installation

About two minutes in MetaTrader 5.

  1. Download AutoPilotFX_EA.mq5 from the button above.
  2. In MetaTrader 5, open File → Open Data Folder.
  3. Copy the file into MQL5/Experts/. If you're updating an existing copy, delete the old .mq5/.ex5 first so MT5's Navigator doesn't end up listing two versions side by side.
  4. Back in MT5, right-click Expert Advisors in the Navigator and choose Refresh. Then right-click the EA itself → Modify → press F7 in MetaEditor to compile (confirm "0 errors, 0 warnings").
  5. Drag AutoPilotFX_EA onto a chart (tested on EURUSD) and tick Allow Algo Trading in the dialog's Common tab. You also need the global “Algo Trading” button in MT5's top toolbar switched on — both have to be enabled, or every order gets silently rejected with “auto trading disabled by client”.
  6. In the Inputs tab, InpPreset defaults to Auto — it self-calibrates to whatever chart it's on, so you can just confirm and go. Switch it to Forex / Crypto / Metals / Index for a fixed category bundle instead, or Custom to set each value yourself — see the Key Inputs table below.

Why Auto is the default: the category presets are still a human guess about what's "typical" for forex, crypto, etc. — usually fine, but a specific pair can sit outside that norm (an unusually wide spread right now, say). Auto never hard-codes a number at all: everything recalculates from this instrument's own live ATR and spread continuously, so there's no preset to pick wrong and nothing that can quietly stop fitting later.

These are sane starting points, not tuned or guaranteed settings — validate on a demo account first, same as any default.
